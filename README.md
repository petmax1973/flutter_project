# Flutter Project

Repository pubblico contenente progetti Flutter realizzati durante lo studio.

## Struttura

- **flutter_basics** → progetti base del corso
- **fattura_elettronica** → Web App che estrae automaticamente la FatturaPA da cartelle PEC (XML/P7M/EML) e genera documenti in PDF leggibili.
- **attendance_register** → Applicazione per gestire presenze e appelli offline, dotata di calendario interattivo, storico individualizzato e supporto native per le icone.

## Note

Ogni sottocartella finale rappresenta un progetto Flutter indipendente.
